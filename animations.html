Motion studies

Animated
concepts.

Five distinct animation concepts, each demonstrated live below and explained in plain language — the same ideas that power this whole site.

Concept 01

The typing effect.

Text that writes itself, character by character, then deletes and types the next phrase — like a terminal that never sleeps.

Live demo

How it works

A phrase list lives in a data-typing attribute. JavaScript typeWriter() adds one character per tick, pauses, deletes the phrase, then moves to the next — looping forever via setTimeout. The blinking caret is pure CSS: a small bar with a steps() keyframe animation.

Concept 02

Hover effects.

Four responses to a cursor: lift, invert, zoom and underline — the small physics that make interfaces feel alive.

Hover each card

Lift

Card rises with a soft shadow — depth without weight.

Invert

Colours swap to ink — maximum contrast, zero motion.

Zoom

The lens scales and rotates — a magnifier moment.

Underline

A lime rule slides out from the left edge.

How it works

All four are CSS only, driven by :hover and transition. Lift animates transform: translateY plus box-shadow; invert swaps background-color / color; zoom scales a child element; the underline animates width on an ::after pseudo-element.

Concept 03

The animated background.

A hairline grid that never stops drifting, with two light pulses orbiting through it — depth from the simplest geometry.

Live demo

background-position drifts 44px each loop — the grid appears to slide while every line stays perfectly still.

How it works

Two linear-gradient layers paint vertical and horizontal hairlines every 44px. A keyframe animation moves background-position by exactly one tile size, so the loop is seamless. The pulses are absolutely-positioned dots on an orbit keyframe path with a soft lime glow.

Concept 04

Animated skill bars.

Progress bars that fill to their true value when they scroll into view — data revealing itself, not decorating.

Scroll-triggered
HTML & CSS90%
JavaScript85%
React / Next.js80%
Python75%
SQL / Databases70%

How it works

Each row carries its target in data-skill="90". An IntersectionObserver fires once the row enters the viewport, then JavaScript sets the fill's width to that percentage — CSS transition does the easing. A lime dot marks the tip when the bar settles.

Concept 05

Scroll reveals.

Content waits below the fold, then fades and rises as you reach it — the four tiles ahead are doing it right now.

Watch these appear
Tile 01

Every element with .reveal starts invisible and 26px low.

Tile 02

One IntersectionObserver watches all of them.

Tile 03

On intersect, .visible fades them up with easing.

Tile 04

A --d variable staggers each tile by 80ms.

How it works

The observer adds .visible when a .reveal element crosses a threshold — no scroll-position maths, no library. The staggered delay comes from a CSS custom property, transition-delay: var(--d), so one rule drives the whole page.
